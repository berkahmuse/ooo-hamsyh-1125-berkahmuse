## The reply

> I'm away until Monday — your email is being handled by the office printer, which has jammed on it specifically.

## How it works

`main.ts` writes that single line to `/output/entry.txt`. Nothing else: no
network, no secrets, no dependencies — just one deterministic write, so every
run produces byte-identical output.

```sh
node main.ts
cat /output/entry.txt
```

## Why this line

* It reads like a real away message a person would actually switch on.
* The laugh lands on the first read: the email wasn't merely delayed, the
  office printer — the most universally resented machine in any workplace —
  jammed on that message *specifically*.
* It turns the usual away message instead of repeating the beach, inbox, or
  "limited access" lines.
* Short enough to take in at a glance: every word earns its place.
